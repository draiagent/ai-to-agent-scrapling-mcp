# 本機驗收

以下待使用者在自己的環境執行，不是本次已通過的測試。

1. 記錄 OS、Python、Scrapling 與客戶端版本。
2. 安裝後確認命令 help 能執行；以絕對路徑註冊 MCP。
3. 客戶端列出工具，確認 MCP 握手成功。
4. 提供一個可公開讀取的靜態頁，要求擷取標題、正文及來源。
5. 在瀏覽器人工核對原文片段，記錄時間與工具結果。
6. 用一個有缺漏欄位的頁面測試；Agent 應保留缺漏，不補造。
7. 測試無法取得的網址，應明確報錯而不假裝完成。
8. 對有動態內容的頁另行驗收；結束後檢查瀏覽器與 session 已釋放。

通過標準：可連接、可取得至少一筆真實證據、缺漏及錯誤可識別、未發生超出任務的寫入。將結果附上版本與日期，才能標示該環境已實測。
